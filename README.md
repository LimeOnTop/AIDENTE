# AIDENTE

Веб приложение для подбора персональных рецептов блюд.

## Описание проекта

Это микросервисное приложение состоит из следующих компонентов:

user-service - сервис управления пользователями
auth-api - сервис аутентификации и авторизации
gpt-service - сервис взаимодействия с GPT-моделями
api-gateway - API Gateway для маршрутизации запросов
frontend-service - фронтенд приложение

## Предварительные требования

Перед запуском убедитесь, что у вас установлены:

Docker (версия 20.10.0 или выше)
Docker Compose (версия 1.29.0 или выше)
Go (версия 1.20 или выше, если требуется сборка вне контейнеров)

## Запуск приложения с помощью Docker Compose

Клонируйте репозиторий:

```bash
git clone <ваш-репозиторий>
cd <директория-проекта>
```

Запустите приложение:

```bash
docker-compose up -d
```

Для просмотра логов в реальном времени:

```bash
docker-compose logs -f
```

После успешного запуска приложение будет доступно:
Frontend: http://localhost:3000
API Gateway: http://localhost:8080

## Остановка приложения

Для остановки всех сервисов выполните:

```bash
docker-compose down
```

## Переменные окружения

Основные переменные окружения, которые могут потребоваться для настройки, находятся в файле .env в корне проекта.
